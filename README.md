# SOCIAL-IMADD-Assignment
## Social

A simple Android application built to explore GitHub Actions integration and automated testing workflows.

### Features
- Time-Based Social Suggestions
- Input Validation
- Quick Reset Functionality

### Technologies Used
- Kotlin/Java
- Android Studio
- GitHub Actions
- JUnit for testing

### Setup Instructions
1. Clone this repository
2. Open in Android Studio
3. Sync Gradle files
4. Run the app on emulator or device

### Testing
Run tests using: `./gradlew test`
